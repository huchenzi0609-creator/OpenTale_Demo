# 生长与遍历截面示例

这两组示例由旧人物资料改写为新模式原生窗口。叙事 Markdown 只覆盖选定时刻与此前少量必要经历；共同种子描述可见环境。各窗口的 `orientation.md` 留空，未指定后续任务、必然事件、结局或应得主题。原作的后续不作为世界必须完成的剧本。

## 远山淡影 河岸的夏天

截面：佐知子和万里子刚在战后长崎的河岸木屋安顿。悦子怀着第一个孩子，绪方暂住公寓，二郎白天在公司，藤原经营面店。悦子介绍工作和后续去留尚未展开。

六个入口各自保留眼前日常、有限的认识和关系中的不同分量。英国回忆线及后来的人生事实没有作为全知说明输入。可以向前生活，也可以形成新的记忆和解释，不要求重演原作。

## 败犬不需要安可 午后切面

截面：丽诗离职当天下午两点半，男人刚在收银台放下书并轻咳，丽诗刚抬头；红衣女人仍在小说架边寻找。

五个入口覆盖丽诗、收银台下、萨姐、饮品柜台和小说架边。辞职与旧桌的既有经历作为有限前史；后续交易、夜间发生的事及解释没有写进种子。桌下声响保持感知入口，不指定其身份或象征意义。母亲未作为当前窗口强行加入。

## 使用

在新版工作台的“种子来源”选择带“内置截面示例”的预设。可直接编辑本次创建用的 Markdown，也可“另存为我的预设”。内置文件只读；自定义版本继续保存到当前服务的数据目录。

`preset.json` 和 `window.json` 只放标识与名称；叙事正文在 `story.md`，共同环境在 `shared.md`。这些说明仅供人类阅读，不注入模型。此目录不包含原书文件或完整情节梗概。
