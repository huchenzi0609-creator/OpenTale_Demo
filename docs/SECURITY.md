# 私有配置与本机安全

## 密钥只存后端私有配置

唯一推荐填写位置是仓库根目录 `.env.local`，即 `/Users/huchenzi/Ready4AI/Project_OpenTale/Opentale_Demo/.env.local`。该文件已被 Git 忽略，Unix 权限应为 `600`。公开 `.env.example` 保留空的 key 和非敏感默认参数。

本项目及开发人员不需要查看密钥内容。不要把密钥发给对话、复制到角色 MD、提交进 Git、写入启动命令或前端构建变量。网页没有密钥输入框。后端加载配置，公开接口仅返回是否配置、模型名和安全的限制参数，不返回 key 或服务地址。

修改配置后在没有任务运行时使用网页重新加载。新生成请求使用当前配置；已有任务运行中拒绝 reload，避免半窗口使用不同配置。

## 本机网络边界

默认仅监听 `127.0.0.1:8231`，前端开发使用 `127.0.0.1:5196`。生产前后端同源，没有宽松的 CORS。远程 provider 地址只接受 HTTPS；HTTP 仅用于回环端点。

这个 demo 没有多人认证或公网服务授权设计。不要直接改为 `0.0.0.0` 并公开端口。若将来部署，需要独立审查认证、跨站请求、代理、速率限制与存档访问权限。

## 日志、错误与导出

provider 异常转换成有限安全错误码；不返回 HTTP 原文、请求头、prompt、原始响应或 hidden reasoning。模型推理字段不进入存档或浏览器。服务日志也不得含 Authorization header、密钥或原始 provider 异常。

存档包含人物种子、叙事正文、操作和工程关系证据，可能具有用户创作的私人内容。API 导出只导出对局，不导出 provider 配置、密钥或模型推理。用户如果主动在正文输入个人信息，导出仍会包含该正文；密钥扫描无法代替判断公开叙事内容是否合适。

`runtime/` 保存私有 SQLite 存档、事件和后台服务记录，整个目录不进入 Git。删除对局会移除该对局的快照与事件记录；这是逻辑删除，不保证磁盘页、操作系统备份中的安全擦除。当前没有自动备份；导出的外部副本由用户自行管理。

## 提交前检查

本仓库已启用 `scripts/hooks/pre-commit`，普通提交会先运行密钥与私有路径检查，失败时阻止提交。bootstrap 也会在本仓库没有自定义 hooksPath 时启用它，不覆盖用户已有钩子。手动检查命令如下：

```sh
uv run python scripts/check_secrets.py
git status --short
git diff --cached --stat
```

检查器扫描公开工作树和暂存内容，识别常见 provider/GitHub/AWS token、私钥块及非空 key 配置。发现秘密路径时只报路径，绝不读取文件。忽略文件不被扫描，也不会被打印。

检测不是所有秘密格式的证明；不要把“检查通过”当作允许提交 `.env.local` 或原始日志的理由。若秘密曾被提交，删除文件不能移除历史：必须撤销/轮换密钥并清理发布历史。

## 试验预算

默认离线验收不收费。真实模型测试必须先由用户提供本地配置，并明确选择远程 provider 与预算。调用失败和重试也可能计费。请从单窗口、小并行和明确的调用数开始，检查实际用量后再扩展。

新实验默认总 Token 预算为 128000，允许提高到 512000；该值是整个实验累计准入预算，不是单次输出长度或远程模型上下文声明。`OPENTALE_MAX_OUTPUT_TOKENS` 独立控制每次请求的输出参数，本机接受上限为 32768，实际仍受服务商及模型能力限制。

加载旧存档不会自动提高原预算。先暂停任务，再在网页调整预算并点击“更新本实验预算”；只改输入框或后端上限不会替代这次保存。保存预算保留已用调用和全部 Token 占用，拒绝低于已用值的额度，不调用模型。输出错误中已知用量照常结算，未知用量保留保守占用；加预算并不消除此前可能发生的费用。
