# 生长与遍历合同

新模式 `growth_reading` 使用 schema 6、engine `growth-reading-v1` 和方法语言 3。旧快照和解释器不被原地升级；新数据库是独立的 `graph-runs.sqlite3`。

## 世界与阅读

`GraphState` 只保存小型运行头、窗口、读轨、计数和配置。正文在 CAS，节点、边、方法、试写、反馈、会话和请求分别索引；列表和页面不重建累计世界。

`NarrativeNode` 是一份可进入的文字构造，`NarrativeLink` 有显式 `growth` 与自由说明的 `association`。生长可以多父源，一般关联可以成环；相同正文哈希不自动合并叙事身份。输入依赖另存，不自动创建叙事边。工程提交顺序不是故事时间。

窗口有自己的工作点、前沿、方向、版本及方法。读轨有入口、游标、书签、图视界和 `read_seq`。访问和呈现分别推进阅读序号，阅读不会改变世界提交；读者显式发布新构造时增加图提交和书签，保留原游标及阅读序号。

节点、方法和原文以精确版本引用。来源区间采用 Unicode 码点半开范围，前端转换 UTF-16。呈现只能使用本轨实际访问过的区间；私有叙事来源的派生仍私有。方法、工作判断和技术来源只出现在工作记录中。

## 方法与动作

方法语言 3 选择节点引用、共享分组和关系。默认去重成员，重复位置须显式表达；增加关系不会复制全文。方法可以保存旧方法及反馈作为依据，新版本通过试用、采用和再次应用获得执行证据。评议可以引用另一个评议方法；没有固定反思阶数。

`decide / draft / render` 是模型能力接口，不是全员三阶段屏障。决定每次选择一个主动作，宿主执行并返回收据：查询、读取页面、检查／应用／改版／采用方法、试写、发布、访问、呈现、回应或等待。读写位置都可以发起试写和发布。

查询包括叙事节点、边、视图、方法和回应。目录、来源页及结构页提供句柄、版本和后续范围；模型只能引用实际交付的能力。方法的结构程序引用当前可见节点，不执行任意 Python 或 shell。JSON 修复沿原冻结输入继续，失败尝试计费单列。

原始选材的全文不被页面替代；实际已见范围明确记录。自己的未处理回应独立交付，其他回应可继续查询。上下文目标影响页面大小，独立的传输保护边界仍执行预检。阅读转述只取得实际访问的正文、本轨近期阅读和自身工作判断，不读取所有窗口最新续延。

## 并发与恢复

每个作用域串行安装，不同窗口和读轨可以并发；传输并发受显式 `max_parallel` 设置约束。世界补丁使用短事务。持续生长有独立窗口工作循环，某个作用域出错不阻止其他作用域；主动等待后只在世界变化时唤醒，不进行模型轮询。

`graph_commit`、`work_seq`、`read_seq` 分开。请求记录精确 frame、投影、尝试、方法和结果。接受结果后中断，会按原方法与来源安装，不套入后来采用的方法，也不重新付费。调用前原子保存预留；中断的未知用量保守结算，不能永久滞留为预留。

`max_calls / max_tokens / max_windows` 默认 `null`。有显式预算时执行准入和生长提交控制；读取、试用及真实失败均透明记账。暂停保留工作位置。API 字段错误、服务商错误和密钥匹配使用固定安全信息，不返回原始请求或错误体。

## HTTP 与存档

`/api/graph-runs` 新建、列出和读取新实验；`growth/{step,start,pause}` 与 `readings/{id}/{step,start,pause}` 独立控制。图、方法、试用、反馈、访问和呈现可以分页读取，节点按版本取得原文。`limits / fork / imports` 为明确操作，删除根不删除其他存档仍引用的正文。导出使用 NDJSON 流。

`/api/graph-presets` 保存可变窗口预设：每窗口的 `story.md / orientation.md` 保存叙事内容，JSON 保存元数据。版本内容校验、无符号链接读写、文件锁、完整暂存和原子当前指针防止冲突及半发布。

旧资料只通过用户选定的文字及来源导入新根，不从历史回合或视图组伪造生长关系。对象完整性、事件完整性、状态头重建、确定性内核重放是不同验证层；它们不能替代真实模型的文学与意图评判。
