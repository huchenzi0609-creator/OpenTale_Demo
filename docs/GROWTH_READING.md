# 叙事生长与阅读遍历：离线验收与使用范围

新模式使用 `growth_reading`、schema 6、方法语言 3。旧 `/api/runs`、旧预设和旧存档仍使用原合同。新图的节点是已提交的叙事构造，生长边需要显式声明父源，一般关联可以形成环；模型输入依赖另存为执行证据。

## 本地使用

工作台中选择新版生长与阅读入口，创建生成窗口、各窗口初始 Markdown、工作方向及共同入口文字。生长工作与读轨分别推进。一次工作动作可能只是查看方法、读取页面、试写、回应或修改方法；公开图提交只在发布等实际图操作后增加。

从节点建立读轨后，阅读动作先保存访问，再将已访问的精确原文区间呈现为读段。两条读轨各自保留入口、游标、访问序号、观察图版本和方法。它们可以在同一图版本上连续阅读，也可以留下未读枝桠。访问和呈现都会推进该读轨的 `read_seq`，因此访问列表中的序号可以有间隔。

正文中的来源位置采用 Unicode 码点半开区间 `[start, end)`。显示来源时通过节点 ID、节点版本及正文引用定位；正文区保持第三人称叙述。调试记录中的方法、试用、回应、访问和来源信息不属于人物已知的技术来处。

窗口预设通过 `/api/graph-presets` 单独保存。`story.md` 保存初始叙事文字，`orientation.md` 保存工作方向，`window.json` 与 `preset.json` 保存系统元数据。更新需要 `expected_version`，旧版本保持可用；载入新预设使用 `preset_id: "graph:<预设ID>"`。原人物预设也可以作为新实验的显式入口导入。

## 离线验证

从仓库根目录运行：

```sh
.venv/bin/python scripts/verify_growth.py
.venv/bin/python -m pytest -q tests/test_growth_core.py tests/test_growth_provider.py tests/test_growth_runtime.py tests/test_growth_api.py tests/test_growth_presets.py
```

脚本直接建立 `Settings()` 和临时 SQLite 存储，使用 fixture，不加载 `.env.local`、不读取配置中的密钥、不调用模型 API。默认进行 22 个生长工作动作，每条读轨进行 9 个工作动作，以两条记录一页检查分页。`--actions`、`--reading-steps` 和 `--page-size` 可调整这次离线验证；这些选项不构成正式实验的预算限制。

输出 JSON 包含以下可以复核的记录：

- 两个生成窗口各自经历查看、应用、试写、结果回应、方法改版、精确采用、再次应用、再次试写及发布。
- 共同入口的分枝、显式多父源交汇和成环的一般关联。
- 评议方式的旧版本、实际组织、反馈依据、新版本及新组织。该额外样例使用显式的离线评议文字作为输入。
- 同一图版本上的两条不完全读轨、真实访问、呈现及未访问节点数。
- 私人节点及其后续派生保持私有；另一窗口不能把私有来源作为父源。
- 小页查询没有重复对象头且能够结束；不可变对象历史逐页验证完成。
- 确定性内核重新执行生长补丁、关联、访问、呈现及核心方法采用，并比较保存结果。

运行测试还覆盖接受结果后中断、安装后中断、方法变化后的旧请求恢复、格式修复的有限反馈、已计费拒绝结果、调用及 Token 预算预检、跨来源写入拒绝、预设冲突、符号链接防护和发布中断。

## 模型工作边界

适配器使用现有 DeepSeek 后端传输，提供 `decide`、`draft`、`render` 三个小步入口；确定性内核执行动作。模型只可使用当前作用域实际提供的目录句柄。`query` 返回目录，`read_page` 取得版本及范围明确的真实页面；后续页需要再次读取。目录简介、已见原文和完整采用方法的指令分别表达。

试写和阅读请求保存所用方法的精确 ID、版本与完整指令，以及实际来源页面、工作收据和交付的反馈。选材、分组与关系组织可以通过方法语言 3 的结构程序执行；评议可以标明精确评议方法。改变方法后，已经接受的请求仍按原冻结版本安装。

选中的来源和完整交付的回应不会由适配器静默截断。控制信息、来源或反馈超出配置容量时返回可恢复的容量错误。容量以保守字符边界预检，不能视为服务商精确 Token 容量的证明。模型格式修复、失败尝试和未知用量进入调用记录；已经接受的结果恢复时复用原结果。

## 验证的限度

fixture 的动作选择和文字是离线机制样例。新方法被实际采用、新组织被执行、不同读轨留下不同路径，都能证明对应机制发生过；这些事实不能独立证明真实模型的文学质量、创造能力、意图或高阶思考。

`object_integrity` 检查不可变对象与正文引用；`deterministic_kernel_replay` 重新执行确定性核心动作。模型输出和普通工作控制仍是冻结边界输入，报告明确保留 `semantic_replay: false`。哈希完整、事件完整、状态重建及核心动作重放不应合并成“全量文学语义验证通过”。

大世界通过索引、引用与分页避免每次物化完整历史。实际新增的独特节点和文字仍会正常增加存储；离线小样例没有证明任意规模的吞吐、资源上界或服务商实际容量。持续工作的暂停、错误和预算恢复由对应作用域保留工作位置。

真实模型检验属于单独的 P7 阶段，需要用户明确配置与测试预算。此离线验收没有执行 P7，也没有以 fixture 的结果替代真实文本审读。
